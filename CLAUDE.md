### Как запускать ревью здесь

- `/code-review` выполняется форком без Agent tool, то есть одним агентом. Для параллельного ревью нужен Workflow;
  многоагентный запуск — только с явного согласия пользователя в текущей сессии.
- В облачном контейнере 4 CPU, поэтому один workflow держит только 2 агента одновременно. Быстрее запускать
  несколько workflow параллельно на непересекающихся частях diff'а (так делали второе ревью: 4 × 2 агента).
- Пробные тесты — через `go test -overlay` (файл пробы лежит вне репозитория, рабочие копии не меняются).
  Рабочие копии HEAD и базы — `git worktree add --detach` во временный каталог; после работы удалить.
- Якоря inline-комментариев должны попадать в строки diff'а (добавленные или контекст хунка с 3 строками).
- Оценки по прайсу API: одноагентное `/code-review max` ≈ $18; ultra-ревью с двойной перепроверкой ≈ $230.
