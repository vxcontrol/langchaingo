## Как пользоваться пробными тестами

Это одноразовый код агентов, а не тесты репозитория. Каждый каталог — одна проба; `package` в файле совпадает с
пакетом, который проба проверяла. Запускались так, не трогая рабочую копию:

```sh
cd <checkout> && go test -overlay=overlay.json -run '^TestProbe' -v ./<pkg>/
# overlay.json: {"Replace":{"<checkout>/<pkg>/zz_probe_test.go":"<abs path>/probes/<name>/probe_test.go"}}
```

При исправлении пробу удобно превратить в регрессионный тест: скопировать в пакет, переименовать и оставить только
проверки. Каталоги с точкой в начале имени `go` пропускает, поэтому эти файлы сборку и `go test ./...` не затрагивают.
